 # 🔬 Wafer Fault Detection using Machine Learning

## 📌 Project Overview

Wafer Fault Detection is an end-to-end Machine Learning project designed to
identify whether a semiconductor wafer is **faulty or non-faulty** based on
manufacturing and sensor-related features.

The project implements a complete Machine Learning pipeline, including data
ingestion, data validation, preprocessing, model training, model evaluation,
best model selection, and prediction.

## 🎯 Objective

The main objective of this project is to develop a reliable classification
system that can automatically detect potential wafer faults and assist in
the quality-control process of semiconductor manufacturing.
